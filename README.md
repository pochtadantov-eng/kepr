# Kepr

Визуальное (демо) банковское приложение для iPhone в виде PWA. Все деньги, карты, переводы и котировки вымышленные. Реальных платежей нет.

## Запуск
Любой статический хостинг (например GitHub Pages) или локально: `python3 -m http.server` и открыть в Safari.
На iPhone: Safari → «Поделиться» → «На экран Домой».

## Что есть
PIN-экран, счета и карта (заморозка, реквизиты), переводы (по телефону, на карту, между своими), платежи, накопительный счёт с процентами, инвестиции с живыми котировками, «Город» с кэшбэком, чат поддержки, уведомления, поиск, операции с деталями.
Данные хранятся в localStorage; «Ещё → Сбросить демо-данные» возвращает исходное состояние.

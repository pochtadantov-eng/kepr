# kepr

В репозитории две версии игры про выживание:

- **«Долгая ночь»** (`app/`) — 3D-выживание, приложение для Android.
- **Режим для Roblox** (`src/`) — то же выживание внутри Roblox, собирается через Rojo.

## «Долгая ночь» — приложение для Android

### Установка
1. Открой страницу **Releases** репозитория на GitHub (на телефоне можно в браузере).
2. В самом верхнем релизе нажми на файл `dolgaya-noch.apk`, чтобы скачать его.
3. Открой скачанный файл и нажми «Установить». Если телефон спросит, разреши установку из этого источника.

Новая версия собирается автоматически после каждого изменения в папке `app/`.
Обновление ставится поверх старой версии, сохранения остаются.

### Как устроено
```
app/www/                   сама игра (HTML + three.js), работает без интернета
app/assets/                иконка и заставка
app/android-overrides/     полноэкранный режим (MainActivity)
app/capacitor.config.json  настройки Android-приложения (Capacitor)
app/android-debug.keystore постоянный ключ подписи, чтобы обновления ставились поверх
.github/workflows/app.yml  сборка APK и публикация релиза
```

# Режим для Roblox

Режим «приключение и выживание»: днём собираешь ресурсы и крафтишь, ночью отбиваешься от зомби.
С каждой ночью зомби становится больше, они крепче и быстрее. Сколько дней ты продержишься?

## Как играть

| Действие | Управление |
| --- | --- |
| Рубить дерево, добывать камень, собирать ягоды, пить из озера | подойти и зажать **E** |
| Съесть ягоды | **F** или кнопка справа |
| Скрафтить предмет | кнопки в панели «Крафт» справа |
| Взять меч / ударить | **1**, затем **ЛКМ** |

- **Голод и жажда** постоянно падают. Если одно из них дойдёт до нуля, начнёшь терять здоровье.
- **Здоровье** само восстанавливается, только если ты сыт и напился (оба показателя выше 50), и быстро — у костра.
- **Ночью** вокруг игроков появляются зомби. На рассвете они сгорают, а все выжившие получают +1 день.
- **Смерть** обнуляет серию дней и забирает все ресурсы. Лучший результат сохраняется в колонке «Рекорд».

### Крафт

| Предмет | Цена | Что делает |
| --- | --- | --- |
| Меч | 3 древесины, 2 камня | 25 урона зомби перед тобой |
| Костёр | 5 древесины, 3 камня | светит и лечит всех рядом, горит 4 минуты |
| Стена | 4 древесины | зомби приходится её ломать |

Все числа (длительность дня, урон, цены, количество зомби) лежат в `src/shared/Config.luau`: меняй их, как хочешь.

## Как запустить (Rojo)

1. Установи [Rokit](https://github.com/rojo-rbx/rokit) и в папке проекта выполни `rokit install`: он поставит Rojo нужной версии.
2. Установи плагин Rojo в Roblox Studio: `rojo plugin install`.
3. Запусти сервер синхронизации: `rojo serve`.
4. В Roblox Studio создай новое место из шаблона **Baseplate**, открой вкладку **Plugins → Rojo** и нажми **Connect**.
5. Нажми **Play**. Мир (земля, озеро, деревья, камни) сгенерируется сам при старте.

Чтобы рекорд сохранялся при игре в Studio, включи **Game Settings → Security → Enable Studio Access to API Services**
(место нужно сначала опубликовать). Без этого игра работает, просто рекорд не сохраняется между запусками.

Собрать файл места без Studio-синхронизации: `rojo build -o kepr.rbxlx`.

## Структура

```
src/
  shared/Config.luau            настройки режима (общие для сервера и клиента)
  server/init.server.luau       точка входа сервера
  server/World.luau             генерация карты и ресурсов
  server/DayNight.luau          смена дня и ночи
  server/Survival.luau          голод, жажда, еда, питьё
  server/Zombies.luau           появление и поведение зомби
  server/Crafting.luau          меч, костёр, стена
  server/PlayerData.luau        инвентарь, таблица игроков, рекорды
  client/init.client.luau       интерфейс игрока
  character/Health.server.luau  отключает стандартную регенерацию здоровья
```
